Original boot.img cmdline (aboot header, no androidboot.* extras):
  earlycon root=PARTUUID=a7ab80e8-e9d1-e8cd-f157-93f69b1d141e console=ttyMSM0,115200 no_framebuffer=true rw

HandsomeMod template:
  earlycon console=tty0 console=ttyMSM0,115200 root=/dev/mmcblk0p14 rw rootwait

Our first 6.18 boot.img:
  earlycon console=tty0 console=ttyMSM0,115200 root=PARTUUID=a7ab80e8-e9d1-e8cd-f157-93f69b1d141e rw rootwait

Proposed cmdline for the trimmed kernel
---------------------------------------
  earlycon console=ttyMSM0,115200 root=PARTUUID=a7ab80e8-e9d1-e8cd-f157-93f69b1d141e rw rootwait

Parameter notes
---------------
earlycon
  Enable early UART before the full console driver. Useful if the kernel
  dies before ttyMSM0 is registered. Keep.

console=ttyMSM0,115200
  MSM8916 BLSP UART2. This is the real serial console on the stick.
  Drop console=tty0: there is no panel, and we disabled DRM.

root=PARTUUID=a7ab80e8-e9d1-e8cd-f157-93f69b1d141e
  mmcblk0p14 / rootfs partition. Prefer PARTUUID over /dev/mmcblk0p14
  because the name is stable across driver probe order.

rw
  Mount root read-write. Matches the live Debian install.

rootwait
  Wait for eMMC. Safer than the original image (which omitted it) when
  sdhci-msm is a bit slower to probe on 6.18.

Dropped on purpose
------------------
no_framebuffer=true
  Android/downstream leftover. Mainline has no equivalent; DRM is off.

androidboot.emmc=true
androidboot.serialno=...
androidboot.baseband=msm
mdss_mdp.panel=0:dsi:0:
  Parsed by Android userspace / downstream MDP. Mainline ignores them.
  Serial/baseband identification is not needed for Debian.

clk_ignore_unused / pd_ignore_unused
  Not used. Enable later only if a clock/power-domain gets gated before
  a consumer (typical symptom: Wi-Fi or modem firmware load hangs).
