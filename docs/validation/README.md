## 当前验收边界（重要）

- **已验证**：UFI103s 的 `venus-4g-gpu` 变体在 7.2.9 上**整机刷入**
  （boot + max rootfs，含无 WiFi 开箱即用）；`minimal` 变体 **RAM 启动**验证。
- **未验证**：其余四个功能变体的硬件启动、除 max 外六张 rootfs 的整机矩阵、
  四块 WCN3660B 板、SIM 业务、Windows/macOS RNDIS、长稳与掉电。
  `minimal` 尚未从闪存做首启验收。
- **已知限制**：Venus MPEG-4 硬解固件 fatal（新旧内核均复现，非回归）；
  持续负载散热（满频约 45–160 秒到 80°C）。
